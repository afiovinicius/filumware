# Attacks Methods

## Types

| Attack | Description |
| ----------------------- | ----------------------------------------------------------------- |
| Deauthentication Attack | Abuso de mensagens de desconexão para interromper conexões Wi-Fi. |
| Handshake Capture | Captura de informações de autenticação para análise de segurança offline. |
| WPA/WPA2 Password Cracking | Tentativas de descobrir senhas fracas de redes protegidas. |
| WPS PIN Attack | Exploração de implementações vulneráveis do mecanismo WPS. |
| PMKID Attack | Exploração de informações de autenticação WPA/WPA2 para auditoria de senhas. |
| KRACK | Vulnerabilidade histórica no mecanismo de negociação de chaves WPA2. |
| Wi-Fi Jamming | Interferência de radiofrequência para prejudicar a comunicação. |
| Brute Force | Tentativas sistemáticas de descobrir credenciais. |
| ARP Spoofing | ARP Manipula associações entre IP e MAC. |
| DNS Spoofing | DNS Tenta manipular a resolução de nomes. |
| DNS Hijacking | DNS Redireciona consultas para infraestrutura controlada pelo atacante. |
| DHCP Spoofing | DHCP Introduz um servidor DHCP não autorizado. |
| IP Spoofing | IP Falsifica o endereço IP de origem. |
| TCP Session Hijacking | TCP Tenta assumir ou interferir em sessões de comunicação. |
| SYN Flood | TCP Explora o estabelecimento de conexões para causar indisponibilidade. |
| Man-in-the-Middle (MITM) | Múltiplas camadas Intercepta ou interfere na comunicação entre duas partes. |
| Packet Sniffing | Múltiplas camadas Captura e analisa tráfego de rede. |
| VLAN Hopping | Ethernet / VLAN Explora configurações inadequadas de segmentação. |
| BGP Hijacking | BGP Anuncia rotas de rede indevidas para desviar tráfego. |
| DNS Cache Poisoning | DNS Introduz respostas DNS falsas em caches. |
